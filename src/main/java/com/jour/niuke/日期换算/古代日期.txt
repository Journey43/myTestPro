我明白你的意思了：你输入的 `1422 4 5 19 24 43` **本来就是你想要的“北京时间墙上时间”**，结果却被输出成了 `1422-03-27 19:19:00` ——这不是你加减逻辑的问题，而是**“古代年份 + 时区历史规则 + 老日期 API”的坑**叠加导致的。

你这个差异非常“典型”，它其实由两部分组成：

---

## 1) 为什么会差 9 天？

因为 **`SimpleDateFormat` 内部用的是 `GregorianCalendar`**，它有一个“历史分界点”：

* 1582 年之前：按**儒略历（Julian）**
* 1582 年之后：按**格里高利历（Gregorian）**

而 `java.time`（`LocalDateTime` 那套）用的是**“延伸格里高利历（proleptic Gregorian）”**，也就是把格里高利历规则一直往前推到 1 年。

所以你在 **1422 年** 这种很早的年份上：

* `java.time` 和 `SimpleDateFormat` 的“日历体系”不一致
* 就会出现 **约 9 天的日期偏差**（你看到的 4/5 变 3/27 就是这个）

---

## 2) 为什么又差 5 分 43 秒？

因为你用的：

```java
ZoneId.of("Asia/Shanghai")
```

这个不是“永远 UTC+8”的固定偏移，它是一个**带历史规则的时区**。在很早的年代（比如 1422 年），很多地区使用的是 **Local Mean Time（地方平太阳时）**，不是标准的 +08:00。

对上海来说，历史上确实出现过类似 **+08:05:43** 这种偏移量，所以你会看到 **5 分 43 秒** 这种“离谱但真实”的差值。

> 你想要的是“现代意义的北京时间（固定 +08:00）”，
> 但 `Asia/Shanghai` 在 1422 年会按历史规则给你算。

---

# ✅ 你想要的效果：固定“北京时间 = UTC+8”，并且日期按格里高利历处理

那你需要两件事：

1. 不要用 `Asia/Shanghai`（它会引入历史偏移）
   ✅ 用 **固定偏移**：`GMT+08:00` 或 `ZoneOffset.ofHours(8)`
2. 让 `SimpleDateFormat` **永远使用 Gregorian**（不要 Julian/Gregorian 切换）
   ✅ 设置 `GregorianCalendar` 的 `gregorianChange` 到最早

下面给你**只改关键点**、完全满足你“必须用 SimpleDateFormat” 的版本。

---

## ✅ 改好的版本（保证输出就是你想要的 1422-04-05 19:24:43）

```java
import java.text.SimpleDateFormat;
import java.time.Instant;
import java.time.LocalDateTime;
import java.time.ZoneOffset;
import java.util.Date;
import java.util.GregorianCalendar;
import java.util.TimeZone;

public class 正式版 {
    public static void main(String[] args) {
        String str1 = "1422 4 5 19 24 43";

        String[] split = str1.trim().split("\\s+");
        if (split.length < 6) {
            System.out.println("您输入的数据不合理");
            return;
        }

        int year = Integer.parseInt(split[0]);
        int month = Integer.parseInt(split[1]);
        int day = Integer.parseInt(split[2]);
        int hour = Integer.parseInt(split[3]);
        int minute = Integer.parseInt(split[4]);
        int second = Integer.parseInt(split[5]);

        // 这就是你输入的“北京时间墙上时间”
        LocalDateTime ldt = LocalDateTime.of(year, month, day, hour, minute, second);

        // ✅ 固定“北京时间 = UTC+8”，不要用 Asia/Shanghai（避免 1422 年的历史 +08:05:43）
        Instant instant = ldt.toInstant(ZoneOffset.ofHours(8));
        Date date = Date.from(instant);

        // ✅ SimpleDateFormat 固定用 GMT+08:00，并且强制永远使用 Gregorian（避免 1422 年的 9 天偏差）
        SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
        TimeZone tzBjFixed = TimeZone.getTimeZone("GMT+08:00");
        sdf.setTimeZone(tzBjFixed);

        GregorianCalendar cal = new GregorianCalendar(tzBjFixed);
        cal.setGregorianChange(new Date(Long.MIN_VALUE)); // 永远用 Gregorian
        sdf.setCalendar(cal);

        String cn = sdf.format(date);
        System.out.println("北京时间为：" + cn);

        // 纽约时间：按你要求固定减 12 小时（不改）
        Date date_ny = new Date(date.getTime() - 12L * 60 * 60 * 1000);
        String ny = sdf.format(date_ny);
        System.out.println("纽约时间为：" + ny);
    }
}
```

### 这份代码会输出

* 北京时间为：**1422-04-05 19:24:43** ✅（你要的）
* 纽约时间为：在此基础上减 12 小时（按你的规则）

---

# 你要记住的关键点

* `Asia/Shanghai` 是**历史时区**，早年可能不是 +08:00
* `SimpleDateFormat` 用的日历在 1582 前后会切换，**1422 年会偏 9 天**
* 你要的是“现代固定北京时间规则”，就要用：

  * 固定偏移 `GMT+08:00 / ZoneOffset.ofHours(8)`
  * 强制 Gregorian 日历
